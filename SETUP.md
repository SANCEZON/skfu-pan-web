# Инструкция по установке и запуску

## Предварительные требования

- Node.js 18+ и npm
- Аккаунт Supabase (для хранения данных)
- (Опционально) Supabase CLI + Docker, если хотите запускать бэкенд локально

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Настройте переменные окружения:
Создайте файл `.env.local` в корне проекта и укажите значения из вашего Supabase:
```
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

3. (Опционально) Локальный Supabase:
Если хотите разворачивать Supabase у себя, используйте Supabase CLI либо предоставленный `docker-compose.yml` из Supabase. После запуска выполните SQL из `supabase/migrations`.

4. Примените миграции:
- Через Supabase Studio → SQL Editor → выполните файлы из `supabase/migrations`
- или через `psql`/Supabase CLI.

5. Запустите dev сервер:
```bash
npm run dev
```

Приложение будет доступно по адресу http://localhost:5173

## Первый вход

1. Откройте приложение в браузере
2. Зарегистрируйте нового пользователя (email/password)
3. После регистрации вы сможете использовать все функции системы

## Основные функции

- **Студенты**: Управление списком студентов, импорт/экспорт CSV
- **Преподаватели**: Управление преподавателями
- **Расписание**: Создание расписания, календарный вид
- **Посещаемость**: Отметка посещаемости на парах
- **Отчёты**: Просмотр и экспорт отчётов
- **Графики**: Аналитика посещаемости
- **Профиль студента**: Детальная информация о пропусках
- **Заметки**: Личные заметки
- **Логи**: Журнал действий
- **Настройки**: Настройка системы и причин отсутствия

## Структура базы данных

Все таблицы создаются автоматически при применении миграции:
- students - студенты
- teachers - преподаватели
- subjects - предметы
- schedules - расписание
- schedule_sessions - сессии пар
- attendance_records - записи посещаемости
- reports - отчёты
- absence_reasons - причины отсутствия
- notes - заметки
- activity_logs - логи действий
- settings - настройки

## Troubleshooting

Если возникают проблемы:

1. Проверьте переменные окружения (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`)
2. Убедитесь, что в Supabase применены миграции и таблицы существуют
3. Посмотрите логи в Supabase Dashboard (Auth, Database → Logs)
4. Очистите кеш и переустановите зависимости:
```bash
rm -rf node_modules package-lock.json
npm install
```
